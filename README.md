# 就活管理ダッシュボード

## 概要

就職活動に関する情報を一元管理するために開発したWebアプリです。

企業情報、選考予定、ES締切、受信メール、GD・面接ログ、自己分析情報などを一つのシステム上で管理できるようにしました。

また、OpenAI APIを活用し、GDや面接の振り返りに対するAIフィードバック機能も実装しています。

---

## 制作背景

就職活動では、

* 企業管理
* ES締切管理
* インターン予定管理
* メール管理
* GD・面接の振り返り
* 自己分析

といった情報が複数のサービスやメモに分散していました。

そこで、それらを一元管理できるシステムがあれば効率的に就職活動を進められると考え、本アプリを開発しました。

## 工夫した点

### 1. 就活情報の一元管理

企業情報、メール、GDログ、自己分析情報などを一つのシステムに統合し、情報の分散を防ぎました。

### 2. AIによる個別最適化フィードバック

一般的なGD・面接評価ではなく、ユーザーが事前に登録した

* 学生時代に力を入れたこと
* 強み
* 弱み
* 就活の軸
* 過去の経験

などの自己分析情報を参照しながらフィードバックを生成する仕組みを実装しました。

これにより、単なる評価ではなく、ユーザー自身の特徴や志向性を踏まえた振り返りや改善提案を受けられるようにしています。

### 3. Googleサービスとの連携

Google SheetsおよびGmailと連携し、就活関連情報を自動取得できるようにしました。

### 4. 継続的な成長を支援する設計

GD・面接ログ、自己分析情報、AIフィードバックを蓄積し続けることで、過去の経験から学びながら改善を繰り返せる仕組みを目指しました。
